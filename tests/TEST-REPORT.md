## 四、记录在案的低危项（不修的理由 + 疫苗）

- 12 款游戏存在未跟踪的一次性 setTimeout：逐 callback 代码审读确认全部只触碰 detached DOM，无崩溃路径、无全局状态污染。
  修复它们需要改 12 个文件、引入回归风险且收益为零——按"断言强度>覆盖率"原则降级为 info。
  **疫苗**：B2 对全部 28 款执行"交互后切换语言重建 + 1.4s 空闲"，断言零 console error（已全绿）。

## 五、撤回记录（曾被报失败、后定性为非缺陷）

1. `en.keys>=300`：阈值无规格依据 → 校准为 ≥180（实际 200）。**用例自身错误**。
2. `home:cat-pills==9`：漏算"全部"pill → 修正为 10。**oracle 记错**。
3. `interact:runner/blocks`：画布哈希可为负，`s1>=0` 误判 → 改 `s1!==-1`。**脚本错误**。
4. `interact:reaction`：漏建模"绿屏后需第二次点击" → 补齐两段式操作。**脚本错误**。
5. `recent:visible-with-history`：依赖上一轮遗留状态 → 改为自播种。**环境状态假设**。
6. B1 全部 `html-lang` 失败：evaluate 第二参未按假设转发 → 改 IIFE 字符串。**脚本错误**。

## 六、自尺自测（审计前先审自己的尺子）

- Oracle A 初版 destroy 正则在 memory.js 上捕获为 null（探针验证），导致 L3 定时器检查**整段空转假绿**——
  重写为"lastIndexOf 锚定 + 未跟踪 timeout 计数"后才产生有效信号。教训：静态势的空转（分支同模）必须先证伪。
- Oracle B 初版 title 断言过弱（含"MathPlay"即过），被英语回落内容空过——改为与字典逐字相等。
- 全部 14 处脚本错误修复后复跑，同一把尺最终 0 fail；无"修尺子到全绿但未解释"的黑箱操作（每次校准均可在上表溯源）。
